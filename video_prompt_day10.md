## 5. Analyse the audio with Whisper (Windows)

This is how the timings in this file were produced (same workflow as Day 9).

1. **Create a virtual environment and install** (PowerShell, Python 3.10):
   ```powershell
   py -3.10 -m venv whisper-env
   .\whisper-env\Scripts\python.exe -m pip install faster-whisper
   ```
2. **Run the `run_whisper.py` script from Day 9's file** (`small` model, `language="en"`, `word_timestamps=True`, `beam_size=1`, `condition_on_previous_text=False`, `temperature=0.0`).
   ```powershell
   .\whisper-env\Scripts\python.exe run_whisper.py audio.mp3 whisper_out.json
   ```
3. **Cross-check with the real pauses:**
   ```powershell
   ffmpeg -i audio.mp3 -af "silencedetect=noise=-26dB:d=0.15" -f null - 2>&1 | Select-String "silence_(start|end)"
   ```
4. **Build the timing map:** use the end of each silence as the phrase start, use Whisper word times for emphasis words, keep your script's spelling, and place scene cuts in the middle of a pause.

**Notes for this audio**
- Whisper in English mode wrote this Telugu-English narration as an English translation. Word *times* are still usable, but the word *order* inside a sentence can differ from the Telugu (for example the Instagram/Follow and Contact lines), so those are marked ≈.
- Whisper sometimes starts a word slightly before the true start (for example "Transient" at 38.7 s versus the pause end at 38.89 s). Pause ends were preferred for phrase starts.
