[Explaining – Main Concept]

Welcome to NDR EdTech!

AWS S3 nunchi Snowflake ki data load cheyyadaniki mainly ee steps follow avutham.

First, AWS S3 lo bucket create chestham.

Second, data files ni S3 bucket lo upload chestham.

Third, Snowflake lo FILE FORMAT create chestham.

Fourth, S3 ki connect avvadaniki STORAGE INTEGRATION create chestham.

Fifth, EXTERNAL STAGE create chestham.

Finally, COPY INTO command use chesi data ni Snowflake table loki load chestham.

[Real-Time Project Example]

Oka Banking project example teesukundham.

Mana CUSTOMER data CSV files AWS S3 bucket lo land ayyayi.

Ippudu Snowflake lo required objects create cheddham.

SQL commands chuddam!

CREATE FILE FORMAT CSV_FORMAT
TYPE = CSV
SKIP_HEADER = 1
FIELD_OPTIONALLY_ENCLOSED_BY = '"';

CREATE STAGE CUSTOMER_STAGE
URL = 's3://my-bank-bucket/customer/'
STORAGE_INTEGRATION = MY_S3_INTEGRATION
FILE_FORMAT = CSV_FORMAT;

Ippudu data load cheyyadaniki:

COPY INTO CUSTOMER
FROM @CUSTOMER_STAGE;

Anthe! S3 lo unna CSV data Snowflake CUSTOMER table loki load avuthundhi.
