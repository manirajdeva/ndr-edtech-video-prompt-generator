[Real-Time Project Example]

Oka Banking Data Engineering project example teesukundham.

Daily morning 6 AM ki customer data load avuthundhi.

Data load complete ayyaka transformation run avvali.

Transformation complete ayyaka reporting table update avvali.

Ippudu first Task create cheddham!

CREATE TASK CUSTOMER_TASK
WAREHOUSE = ETL_WH
SCHEDULE = 'USING CRON 0 6 * * * Asia/Kolkata'
AS
INSERT INTO CUSTOMER_REPORT
SELECT * FROM CUSTOMER_STAGE;

Task create chesina ventane automatic ga start avvadhu.

First RESUME cheyyali!

ALTER TASK CUSTOMER_TASK RESUME;
