[Explaining – Main Concept]

First, Stream!

Stream source table lo jarigina INSERT, UPDATE and DELETE changes ni track chesthundhi.

Second, Task!

Task automatically SQL processing ni schedule chesthundhi or Stream lo changes available unnappudu execute chesthundhi.

Ippudu ee rendu combine chesthe automated CDC pipeline build cheyyachu.

[Real-Time Project Example]

Oka Banking project example teesukundham.

Mana CUSTOMER table source table.

CUSTOMER_STREAM create chestham.

CREATE STREAM CUSTOMER_STREAM
ON TABLE CUSTOMER;

Ippudu target table lo changes process cheyyadaniki Task create chestham.

CREATE TASK CUSTOMER_CDC_TASK
WAREHOUSE = ETL_WH
SCHEDULE = '1 MINUTE'
WHEN SYSTEM$STREAM_HAS_DATA('CUSTOMER_STREAM')
AS
INSERT INTO CUSTOMER_AUDIT
SELECT
    CUSTOMER_ID,
    CUSTOMER_NAME,
    METADATA$ACTION,
    METADATA$ISUPDATE
FROM CUSTOMER_STREAM;

Ippudu Task ni RESUME chestham.

ALTER TASK CUSTOMER_CDC_TASK RESUME;

New changes vachinappudu Stream data available ga untundhi.

Task schedule prakaram execute ayi changes ni target table ki process chesthundhi.
