[Explaining – Main Concept]

Snowflake Stream ante table lo jarigina data changes ni track cheyyadaniki use chese Change Data Capture mechanism.

Simple ga cheppalante, INSERT, UPDATE and DELETE operations ni identify cheyyadaniki Streams help chesthayi.

Stream lo mainly three metadata columns untayi.

First, METADATA$ACTION – INSERT or DELETE ani identify chesthundhi.

Second, METADATA$ISUPDATE – update operation lo part aa kaadha ani indicate chesthundhi.

Third, METADATA$ROW_ID – row ni uniquely identify cheyyadaniki use avuthundhi.

[Real-Time Project Example]

Oka Banking project example teesukundham.

Mana CUSTOMER table lo daily thousands of changes jaruguthunnayi.

Ippudu Stream create cheddham!

CREATE STREAM CUSTOMER_STREAM
ON TABLE CUSTOMER;

Changes ni check cheyyadaniki:

SELECT *
FROM CUSTOMER_STREAM;

Ippudu source table lo changes jariginappudu, Stream change records ni expose chesthundhi.

Manam ee changes ni downstream processing kosam use cheyyachu.
