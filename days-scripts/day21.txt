[Explaining – Main Concept]

Welcome to NDR EdTech!

Snowflake lo Resource Monitor ane feature warehouse credit usage ni monitor and control cheyyadaniki use chestham.

Manam credit quota set chesi, usage limit reach ayinappudu notifications or suspension actions configure cheyyachu.

For example, 100 credits limit set chesam anukondi.

50% reach ayithe notification pampinchachu.

100% reach ayithe warehouse suspend cheyyela configure cheyyachu.

Kaani important point enti ante…

Resource Monitors mainly Virtual Warehouse compute credit usage ni monitor chesthayi. Complete Snowflake bill ni control cheyyavu.

[Real-Time Project Example]

Oka Banking project example teesukundham.

Mana ETL warehouse daily data processing kosam run avuthundhi.

Developers testing kosam separate warehouse use chesthunnaru.

Testing warehouse unnecessary ga running lo undakunda Resource Monitor configure cheyyachu.

SQL command chuddam!

CREATE RESOURCE MONITOR DEV_MONITOR
WITH CREDIT_QUOTA = 100
TRIGGERS
ON 50 PERCENT DO NOTIFY
ON 100 PERCENT DO SUSPEND;
