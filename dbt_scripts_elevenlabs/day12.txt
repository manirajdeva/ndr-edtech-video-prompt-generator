NARRATOR: D B T లో mainly four built-in generic tests ఉంటాయి.
NARRATOR: First, unique – ఒక column లో duplicate values ఉండకూడదు.
NARRATOR: Second, not underscore null – column లో null values ఉండకూడదు.
NARRATOR: Third, accepted underscore values – column లో allowed values మాత్రమే ఉండాలి.
NARRATOR: Fourth, relationships – ఒక table లో values ఇంకో table లో exist అవ్వాలి. ఇది foreign key check లాంటిది.
