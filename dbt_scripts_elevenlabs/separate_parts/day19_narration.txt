D B T లో ఇది Incremental Strategy తో control చేస్తాం.

Snowflake లో mainly మూడు incremental strategies ఉంటాయి.

First, merge!

Snowflake లో ఇది default strategy. ఇది unique underscore key base చేసుకుని, matching rows ని update చేసి, కొత్త rows ని insert చేస్తుంది.

Second, delete plus insert!

ఇది matching rows ని first delete చేసి, తర్వాత కొత్త rows ని insert చేస్తుంది.

Third, append!

ఇది కొత్త rows ని మాత్రమే add చేస్తుంది. Existing rows ని update చేయదు. Logs and events లాంటి data కోసం, అంటే మారని data కోసం ఇది బాగుంటుంది.

ఇంకో important setting on underscore schema underscore change. Source లో కొత్త column add అయితే ఏం చేయాలి అని ఇది decide చేస్తుంది.

ignore, fail, append underscore new underscore columns and sync underscore all underscore columns options ఉంటాయి.

merge – Updates matching rows and inserts new rows.

delete plus insert – Deletes matching rows, then inserts.

append – Only adds new rows.

on underscore schema underscore change – Controls what happens when columns change.
