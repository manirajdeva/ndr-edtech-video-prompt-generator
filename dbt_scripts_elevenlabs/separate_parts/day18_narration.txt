D B T లో ఇది Incremental Model తో possible.

First run లో incremental model మొత్తం table ని build చేస్తుంది.

తర్వాత runs లో only కొత్త or changed rows ని process చేసి, existing table లోకి add చేస్తుంది.

Incremental model create చేయడానికి config లో materialized incremental set చేస్తాం.

ముఖ్యమైన రెండు concepts ఉంటాయి.

First, is underscore incremental function. ఇది table already ఉందో లేదో check చేస్తుంది. Incremental run అయితే true వస్తుంది.

Second, this. ఇది current model table ని refer చేస్తుంది.

మనం is underscore incremental block లో, existing table లో ఉన్న latest timestamp కన్నా కొత్త rows ని మాత్రమే select చేస్తాం.

unique underscore key set చేస్తే, D B T same key ఉన్న rows ని update చేస్తుంది. Duplicates అవ్వవు.

మొత్తం table ని మళ్లీ build చేయాలి అంటే, full-refresh option use చేస్తాం.
