D B T లో ఇది Hooks and Grants తో possible.

Hooks అంటే D B T run లో కొన్ని points దగ్గర automatic గా S Q L statements run చేసే feature.

Mainly four types of hooks ఉంటాయి.

First, pre-hook – model run అవ్వడానికి ముందు S Q L run చేస్తుంది.

Second, post-hook – model build అయ్యాక S Q L run చేస్తుంది.

Third, on-run-start – D B T run start అయ్యే ముందు.

Fourth, on-run-end – D B T run complete అయ్యాక.

Permissions కోసం ఇంకా simple option ఉంది, అదే grants config.

Grants config లో ఏ role కి ఏ privilege ఇవ్వాలో చెప్పొచ్చు. D B T model build అయ్యాక ఆ grants apply చేస్తుంది.

మన Snowflake R B A C concepts ఇక్కడ use అవుతాయి.

ఒక Banking project example తీసుకుందాం.
