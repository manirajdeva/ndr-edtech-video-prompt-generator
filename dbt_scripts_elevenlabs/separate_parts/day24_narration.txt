D B T లో configs ని మూడు places లో set చేయచ్చు.

First, D B T underscore project dot Y M L – folder level లో, ఒక folder లో ఉన్న models అన్ని కి.

Second, schema Y M L files – ఒక model కి properties తో పాటు.

Third, model file లో config block – most specific level.

Priority ఏంటి అంటే, most specific config win అవుతుంది. అంటే model లో config block, folder level setting ని override చేస్తుంది.

Important configs ని చూద్దాం.

First, tags – models ని group చేయడానికి.

Second, schema – custom schema name.

Third, alias – table or view name ని మార్చడానికి.

Custom schema name ని D B T default గా target schema తో కలిపి create చేస్తుంది. అంటే dev లో D B T underscore DEV underscore FINANCE లాగా ఉంటుంది.

మన production లో exact schema names కావాలి అంటే, generate schema name macro ని override చేయచ్చు.
