D B T లో data quality check చేయడానికి Tests use చేస్తాం.

D B T లో mainly four built-in generic tests ఉంటాయి.

First, unique – ఒక column లో duplicate values ఉండకూడదు.

Second, not underscore null – column లో null values ఉండకూడదు.

Third, accepted underscore values – column లో allowed values మాత్రమే ఉండాలి.

Fourth, relationships – ఒక table లో values ఇంకో table లో exist అవ్వాలి. ఇది foreign key check లాంటిది.

Tests ని schema Y M L file లో columns కింద define చేస్తాం.

D B T test command run చేస్తే, ప్రతి test ఒక S Q L query గా run అవుతుంది.

ఆ query failing rows ని return చేస్తుంది. Zero rows అయితే test pass, ఒక్క row వచ్చిన test fail.

Duplicate CUSTOMER underscore I D ఉంటే, unique test fail అయ్యి మనకి వెంటనే తెలిసిపోతుంది!

[confident] So, simple గా గుర్తుపెట్టుకోండి!

unique and not underscore null – Protect primary keys.

accepted underscore values – Allows only expected values.

relationships – Checks references between tables.

Every D B T test passes when it returns zero failing rows.
