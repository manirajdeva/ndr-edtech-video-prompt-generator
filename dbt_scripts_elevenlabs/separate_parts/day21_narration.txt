D B T లో ఇది Targets తో possible.

Target అంటే ఒక environment. మనం profiles dot Y M L లో ఒకే project కి dev and prod లాంటి multiple targets define చేస్తాం.

ప్రతి target కి separate schema, warehouse or role set చేయచ్చు.

By default, profiles dot Y M L లో target value లో ఉన్న environment run అవుతుంది. Prod run చేయాలి అంటే, target option తో చెప్పాలి.

ఇంకో useful concept Variables.

Variables ని D B T underscore project dot Y M L లో define చేసి, models లో var function తో use చేస్తాం. Command లో vars option తో values override చేయచ్చు.

Models లో target name check చేసి, dev లో only కొన్ని rows process చేయచ్చు. దీనివల్ల development fast గా, cheap గా ఉంటుంది.

Secrets ని env underscore var తో తీసుకోవాలి.

ఒక Banking project example తీసుకుందాం.

profiles dot Y M L లో రెండు targets define చేస్తాం:

Target – An environment such as dev or prod.

target option – Chooses the environment for a run.

Variable – A reusable value read with the var function.

Production runs should use a separate schema.
