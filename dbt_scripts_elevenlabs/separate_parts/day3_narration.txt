First, D B T Core!

D B T Core open-source tool. ఇది command line లో work చేస్తుంది.

మనం D B T Core ని మన laptop లో లేదా మన own servers లో run చేయచ్చు.

Scheduling and orchestration ని మనం separately set చేయాలి.

Second, D B T Cloud!

D B T Cloud ఒక managed platform.

ఇది web-based I D E, job scheduling, C I support and documentation hosting లాంటి features ఇస్తుంది.

మన infrastructure manage చేయకుండా quick గా start చేయచ్చు.

Learning కోసం D B T Core best option, because మనం commands ని direct గా నేర్చుకుంటాం.

ఈ series లో మనం D B T Core commands use చేస్తాం. అవి D B T Cloud లో కూడా work అవుతాయి.

ఒక Banking project example తీసుకుందాం.

మన Windows laptop లో D B T Core install చేద్దాం.

First, ఒక virtual environment create చేస్తాం. దీనివల్ల మన project packages వేరే projects తో conflict అవ్వవు.

python dash m V env D B T underscore env

ఇప్పుడు ఆ environment ని activate చేస్తాం:

D B T underscore env backslash Scripts backslash activate

తర్వాత Snowflake adapter install చేస్తాం:

pip install D B T dash snowflake

ఈ command D B T Core ని and Snowflake adapter ని కలిపి install చేస్తుంది.

Finally, installation check చేయడానికి:

D B T dash dash version

Version details వస్తే, మన installation ready!
