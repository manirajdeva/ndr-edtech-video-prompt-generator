## 5. Analyse the audio with Whisper (Windows)

This is how the timings in this file were produced. Repeat it whenever you have a new voice-over.

**Requirements:** Windows, Python **3.10–3.12** (very new Python versions such as 3.15 can't install the audio libraries), and ffmpeg on PATH. The first run downloads the `medium` model (about 1.5–2 GB). CPU only is fine, but a 112 s clip takes several minutes.

1. **Create a virtual environment and install** (PowerShell):
   ```powershell
   py -3.10 -m venv whisper-env
   .\whisper-env\Scripts\python.exe -m pip install faster-whisper
   ```
2. **Save this as `run_whisper.py`:**
   ```python
   import json, sys
   from faster_whisper import WhisperModel

   audio, out = sys.argv[1], sys.argv[2]
   model = WhisperModel("medium", device="cpu", compute_type="int8")
   segments, info = model.transcribe(audio, language="te", word_timestamps=True)

   result = []
   for s in segments:
       result.append({
           "start": round(s.start, 2), "end": round(s.end, 2), "text": s.text,
           "words": [{"w": w.word, "s": round(w.start, 2), "e": round(w.end, 2)} for w in s.words],
       })
   json.dump(result, open(out, "w", encoding="utf-8"), ensure_ascii=False, indent=1)
   print("done", info.duration)
   ```
3. **Run it:**
   ```powershell
   .\whisper-env\Scripts\python.exe run_whisper.py audio.mp3 whisper_out.json
   ```
4. **Cross-check with the real pauses** (this catches mismatched lines):
   ```powershell
   ffmpeg -i audio.mp3 -af "silencedetect=noise=-26dB:d=0.15" -f null - 2>&1 | Select-String "silence_(start|end)"
   ```
5. **Build the timing map:** take the word start times from `whisper_out.json`, keep your script's spelling, and place scene cuts in the middle of a pause.

**Known limits seen on this audio**
- Whisper wrote Telugu words in the wrong script or spelling and invented text in the first 30 s. English words, numbers and code names were reliable. Always replace its text with your script.
- If a 30 s clip stalls (one run did), skip the script hint and use the pause list for that part, as done for 0–30 s here.
- If you want the alternative CLI, `whisper "audio.mp3" --model medium --language Telugu --task transcribe --word_timestamps True --output_format json` works where `openai-whisper` installs (Python 3.12 or earlier).
