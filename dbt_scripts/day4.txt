[Explaining – Main Concept]

dbt project create cheyyadaniki dbt init command use chestham.

Ee command oka project folder create chesthundhi. Dheenilo mainly ee folders and files untayi.

First, dbt_project.yml – project configuration file.

Second, models – mana SELECT statements ni ikkada save chestham.

Third, seeds – small CSV files kosam.

Fourth, snapshots – data history track cheyyadaniki.

Fifth, macros – reusable code kosam.

Sixth, tests – custom test queries kosam.

Seventh, analyses – ad-hoc SQL queries kosam.

dbt run chesinappudu target and logs folders automatic ga create avuthayi. Avi Git loki commit cheyyakudadhu.

Important point enti ante… Mana Snowflake credentials ni store chese profiles.yml file project folder lo undadhu. Adhi mana home directory lo dot dbt folder lo untundhi.

[Real-Time Project Example]

Oka Banking project example teesukundham.

dbt init bank_project

Ee command adapter and connection details adugutundhi. Manam snowflake select chestham.

Ippudu dbt_project.yml lo important settings chuddam:

name: 'bank_project'

version: '1.0.0'

profile: 'bank_project'

model-paths: ["models"]

Mana Banking project kosam models folder lo staging and marts ane two sub folders create chestham.
