[Explaining – Main Concept]

dbt lo Seeds ante small CSV files ni dbt project nunchi direct ga Snowflake table ga load cheyyadam.

Seed files ni project lo seeds folder lo save chestham.

dbt seed command run chesthe, prathi CSV file oka table ga create avuthundhi.

Aa table ni models lo ref function tho use cheyyachu.

Seeds ni ye data kosam use cheyyali? Branch codes, country codes, status mappings laanti small and static reference data kosam.

Important point enti ante…

Seeds pedda data files kosam kaadu. Customer or transaction data lanti large or frequently changing data ni seeds ga load cheyyakudadhu. Avi ingestion tools tho load cheyyali.

Seed CSV files Git lo version control lo untayi. Anduke changes track cheyyachu.

[Real-Time Project Example]

Oka Banking project example teesukundham.

seeds folder lo branch_codes.csv file create chestham:

BRANCH_CODE,BRANCH_NAME,CITY

Ippudu seed load cheddham:

dbt seed

Ippudu Snowflake lo BRANCH_CODES table create avuthundhi.

Aa table ni model lo ila use chestham:

SELECT * FROM {{ ref('branch_codes') }}

Ippudu branch details ni customer data tho join cheyyachu.
