[Explaining – Main Concept]

dbt lo oka model ante models folder lo unna oka SQL file.

Aa file lo manam okka SELECT statement matrame rastham. CREATE TABLE or CREATE VIEW rayalsina avasaram ledhu.

Model name ante file name.

dbt run command run chesinappudu dbt aa SELECT ki CREATE statement jodinchi Snowflake lo run chesthundhi.

By default dbt models ni views ga create chesthundhi.

dbt compile chesthe, dbt generate chesina final SQL target folder lo save avuthundhi. Debugging kosam idi chala useful.

[Real-Time Project Example]

Oka Banking project example teesukundham.

Mana TRANSACTIONS table lo prathi customer total transaction amount kavali.

models folder lo customer_total.sql file create chestham:

SELECT
    CUSTOMER_ID,
    SUM(TRANSACTION_AMOUNT) AS TOTAL_AMOUNT
FROM BANK_DB.RAW.TRANSACTIONS
GROUP BY CUSTOMER_ID

Ippudu model run cheddham:

dbt run

Okka model matrame run cheyyalante:

dbt run --select customer_total

Ippudu Snowflake lo result check cheddham:

SELECT * FROM BANK_DB.DBT_DEV.CUSTOMER_TOTAL;

Anthe! Manam CREATE VIEW statement rayakundane view create ayyindhi!
