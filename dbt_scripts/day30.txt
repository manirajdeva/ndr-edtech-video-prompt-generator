[Explaining – Main Concept]

Mana Banking project lo complete data flow:

SQL Server nunchi data AWS S3 loki vasthundhi.

Airflow complete pipeline ni orchestrate chesthundhi.

Finally, Power BI reports ANALYTICS schema nunchi data teesukuntayi.

Mana dbt project lo ee components unnayi.

Sources – RAW CUSTOMER and TRANSACTIONS tables.

Staging models – stg_customers and stg_transactions.

Marts – customer_summary and fct_transactions.

Tests – unique, not_null, relationships and custom tests.

Documentation – model and column descriptions with lineage.

Snapshots – customer history tracking.

Macros and packages – reusable logic.

[Real-Time Project Example]

Oka Banking project example teesukundham.

Staging model:

SELECT
    CUSTOMER_ID,
    UPPER(CUSTOMER_NAME) AS CUSTOMER_NAME,
    CITY
FROM {{ source('bank_raw', 'customer') }}

Mart model:

SELECT
    c.CUSTOMER_ID,
    c.CUSTOMER_NAME,
    c.CITY,
    COUNT(t.TRANSACTION_ID) AS TXN_COUNT,
    SUM(t.TRANSACTION_AMOUNT) AS TOTAL_AMOUNT
FROM {{ ref('stg_customers') }} c
LEFT JOIN {{ ref('stg_transactions') }} t
    ON c.CUSTOMER_ID = t.CUSTOMER_ID
GROUP BY c.CUSTOMER_ID, c.CUSTOMER_NAME, c.CITY

Production deployment kosam commands:

dbt deps

dbt source freshness
