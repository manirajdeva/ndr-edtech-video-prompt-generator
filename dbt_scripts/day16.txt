[Explaining – Main Concept]

dbt lo reusable SQL logic ni Macros ga create chestham.

Macro ante oka function laantidhi. Oka sari rasi, chala models lo use cheyyachu.

Macros ni macros folder lo save chestham.

Macro define cheyyadaniki macro and end macro tags use chestham. Macro ki parameters ivvachu.

Macro ni model lo double curly braces lo call chestham.

Macros tho manaki three benefits untayi.

First, Less code duplication.

Second, Logic oka chota maintain cheyyachu.

Third, Easy changes. Logic marchali ante, okka macro marchithe saripothundhi.

[Real-Time Project Example]

Oka Banking project example teesukundham.

macros folder lo paise_to_rupees.sql file create chestham:

{% macro paise_to_rupees(column_name) %}
    ({{ column_name }} / 100.0)
{% endmacro %}

Ippudu model lo ee macro ni ila use chestham:

SELECT
    TRANSACTION_ID,
    {{ paise_to_rupees('AMOUNT_PAISE') }} AS AMOUNT_RUPEES
FROM {{ source('bank_raw', 'transactions') }}

dbt compile chesinappudu, macro call ni dbt actual SQL tho replace chesthundhi.

Eppudaina conversion logic marchali ante, macro file lo okka chota marchithe, anni models lo update avuthundhi!
