[Explaining – Main Concept]

dbt lo raw tables ni refer cheyyadaniki Sources use chestham.

Sources ni sources.yml ane YAML file lo define chestham. Aa file lo source name, database, schema and tables rastham.

Models lo aa source ni refer cheyyadaniki source function use chestham. Idi ref function laga untundhi, kaani raw tables kosam.

Source tho manaki two benefits untayi.

First, Lineage! Raw tables kuda dbt lineage graph lo kanipisthayi.

Second, Freshness! Source data ela fresh ga undho check cheyyachu.

Freshness kosam table lo oka loaded at column undali. Warn and error limits set chestham.

dbt source freshness command tho check chestham.

[Real-Time Project Example]

Oka Banking project example teesukundham.

models folder lo sources.yml file create chestham:

version: 2

sources:
  - name: bank_raw
    database: BANK_DB
    schema: RAW
    tables:
      - name: customer
      - name: transactions
        loaded_at_field: LOAD_TS
        freshness:
          warn_after: {count: 12, period: hour}
          error_after: {count: 24, period: hour}

Ippudu model lo source ni ila use chestham:

SELECT * FROM {{ source('bank_raw', 'transactions') }}

Freshness check kosam:

dbt source freshness

Data 12 gantalu kanna paatha ayithe warning, 24 gantalu kanna paatha ayithe error vasthundhi!
