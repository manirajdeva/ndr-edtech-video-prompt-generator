[Explaining – Main Concept]

dbt lo SQL ni dynamic ga raayadaniki Jinja ane templating language use chestham.

Jinja lo mainly moodu types of syntax untayi.

First, Double curly braces – oka value or function result ni print cheyyadaniki. Examples: ref and config.

Second, Curly brace percent – loops, if conditions and variables kosam. Idi statements ni run chesthundhi.

Third, Curly brace hash – comments kosam.

Variable create cheyyadaniki set use chestham. Repeat cheyyadaniki for loop use chestham. Conditions kosam if use chestham.

dbt SQL ni warehouse ki pampinchadaniki mundu Jinja ni plain SQL ga compile chesthundhi.

Compiled SQL ni target folder lo chudachu.

[Real-Time Project Example]

Oka Banking project example teesukundham.

Status wise transaction counts kosam ee model rastham:

{% set status_list = ['SUCCESS', 'FAILED', 'PENDING'] %}

SELECT
    CUSTOMER_ID,
    {% for s in status_list %}
    SUM(CASE WHEN STATUS = '{{ s }}' THEN 1 ELSE 0 END) AS {{ s }}_COUNT
    {% if not loop.last %},{% endif %}
    {% endfor %}
FROM {{ ref('stg_transactions') }}
GROUP BY CUSTOMER_ID

Ippudu kotha status add cheyyali ante, list lo okka value add chesthe saripothundhi!
