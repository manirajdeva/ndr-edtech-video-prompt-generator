[Explaining – Main Concept]

dbt lo ready-made code ni Packages ani antaru.

Package ante oka dbt project, dheenilo macros, models and tests untayi. Manam aa package ni mana project lo install chesi use cheyyachu.

Packages ni packages.yml file lo define chestham.

Taruvatha dbt deps command run chesthe, dbt packages ni download chesthundhi. Avi dbt_packages folder lo save avuthayi.

Most popular package dbt_utils. Idi dbt Labs create chesindhi.

dbt_utils lo useful macros and tests untayi. For example, generate_surrogate_key macro and unique_combination_of_columns test.

Packages ni dbt Hub nunchi teesukovachu.

[Real-Time Project Example]

Oka Banking project example teesukundham.

packages:
